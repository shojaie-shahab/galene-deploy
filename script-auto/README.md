# راهنمای استفاده از اسکریپت خودکار نصب Galene

این اسکریپت تمام مراحل نصب سرور ویدئوکنفرانس Galene را روی **Ubuntu 24.04 (Noble)** به صورت خودکار انجام می‌دهد.

## ویژگی‌های اسکریپت

- تنظیم مخزن apt روی `mirror.arvancloud.ir` (برای دانلود سریع داخل ایران)
- نصب پیش‌نیازها: `git`, `golang-go`, `build-essential`, `unzip`
- دانلود کد منبع Galène از GitHub (با fallback به پروکسی در صورت نیاز)
- کامپایل پروژه
- ایجاد یک اتاق (گروه) پیش‌فرض با کاربر `admin`
- نصب و راه‌اندازی سرویس systemd برای اجرای دائمی
- (اختیاری) تغییر پورت HTTPS و باز کردن آن در فایروال
